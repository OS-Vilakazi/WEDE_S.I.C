# **S.I.C — Sport in Cinema**

**S.I.C (Sport in Cinema)** is a web application designed to bring live sporting events—such as Formula 1 races and major football matches—directly to Ster-Kinekor cinema screens across South Africa. This project provides a full-featured multi-page interface for users to browse upcoming fixtures, view photo galleries of live screenings, send booking enquiries, and locate participating cinema venues.

## **Features**

> * **Multi-Page Layout:** Fully responsive static website consisting of index.html, about.html, services.html, gallery.html, enquiry.html, and contact.html.  
> * **Live Screening Ticker:** Prominently displays real-time updates and upcoming match schedules across the top of the homepage.  
> * **Screening Gallery:** Grid-based photo gallery layout capturing match-day atmospheres and venue highlights.  
> * **Dynamic Fixture Listing:** Detailed schedule breakdown for Formula 1 and football events sorted by date, time, and venue screen.  
> * **Interactive Forms:** Accessible enquiry and contact forms with client-side validation logic.  
> * **Consistent Design System:** Custom dark theme styled using CSS variables for clean contrast and responsive layout grids.

## **Getting Started**

### **Prerequisites**

To run or develop this project locally, you only need a modern web browser (e.g., Google Chrome, Mozilla Firefox, or Microsoft Edge).

### **Running Locally**

> 1. Clone or download this repository to your local machine.  
> 2. Open the project directory.  
> 3. Double-click **index.html** or open it using any local web server extension (e.g., VS Code *Live Server*).

## **Technologies Used**

> * **HTML5:** Semantic markup, accessibility features (aria-\* attributes), and structured page layouts.  
> * **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid layout, and keyframe animations.  
> * **JavaScript (ES6):** Dynamic UI interactions and form event handling.  
> * **Google Fonts:** Integrated Typography using *Montserrat*, *Open Sans*, and *Space Mono*.
